# Flipside — React + TypeScript

대화를 기억하고 관계의 다음 행동을 연결하는 AI 영업 SaaS 대시보드입니다.

## 실행

Node.js 22 이상을 권장합니다.

```bash
npm install
npm run dev -- --port 5174
```

브라우저에서 http://127.0.0.1:5174 를 엽니다.

지역 지도 데이터(`public/maps/*.json`)는 저장소에 포함하지 않습니다. `npm run dev`, `npm run build`, `npm test`를 처음 실행할 때 공개 행정구역 경계 데이터를 내려받아 자동으로 생성하므로 인터넷 연결이 필요합니다. 이미 생성되어 있으면 건너뜁니다.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 테스트 실행 |
| `npm run build` | 배포용 빌드 (`dist/`에 생성) |
| `npm run build:maps` | 지역 지도 데이터 강제 재생성 (`public/maps/`) |

해시 기반 화면 전환을 사용하므로 별도 서버 라우팅 설정이 필요 없습니다.

## 주요 기능

| 기능 | 화면 / 동작 |
| --- | --- |
| 오버뷰 | 관계 현황, 추천 행동, 미팅 브리핑, 고객 목록, 최근 기록 |
| 미팅 녹음 | 고객·시나리오·공유 범위 선택 → 타이머 시작 → 종료 → 샘플 분석 |
| 통화 녹음 가져오기 | MP3/M4A/WAV 선택 및 크기·확장자 검증, 파일 없는 샘플 체험 |
| 지정 연락처 수집 | 설정의 연락처 선택·수집 스위치, 날짜별 중복 수집 방지 |
| 기존 고객 입력 | 신규 고객 등록, CSV/엑셀 선택과 샘플 2행 가져오기, 거래 결과 포함 |
| 음성 인식·화자 분리 | 타임스탬프가 있는 샘플 전사, 연결 고객과 화자 이름 수정·확인 |
| 본인 목소리 등록 | 샘플 목소리 프로필 등록, 분석 화면에 등록 상태 반영 |
| 핵심 정보 추출 | 요구사항, 가격 반응, 약속, 구매 시점, 구매 신호, 의사결정자 |
| 관계 기억 | 고객별 최신 대화 정보, 예산·시점·의사결정자 등의 질문과 출처 |
| 관계 타임라인 | 미팅·통화·수주·실패를 날짜순으로 조회 |
| 관계도 | 고객 선택, 우리 팀과 고객 접점, 사람별 근거, 사내 소개 경로 |
| 다음 행동 | 근거 확인, 일정 확정, 완료·취소, 대기·확정·완료 필터 |
| 캘린더 | 월 이동·오늘·날짜 선택·미팅 등록·시간 검증·상세, 확정한 후속 행동 연결 |
| 미팅 전 자동 브리핑 | 과거 대화·남은 약속·구매 일정·거래 경험 요약, 30분 전 시연 알림 |
| 누락 알림 | 시연 시간 하루 이동, 기한 초과 표시, 시간 초기화 |
| 개인·팀 공유 | 기본 공유 범위, 기록·거래별 공유 변경, 내 보기·팀원 보기 필터 |
| 통합 검색 | 회사·담당자·대화 제목·추출 정보·전사 내용 검색, Ctrl/⌘ + K |
| 추가 편의 | 고객 목록/카드 전환, AI 인수인계 요약, 브리핑 텍스트 다운로드 |
